# Tokusetsu 4 GUI化計画

## 概要
同人音楽特設サイトジェネレーター「Tokusetsu 4」を、GUIで操作できるデスクトップアプリにする。

## 現在の課題
- Googleスプレッドシートで設定ファイル（CSV）を作成する必要がある
- 編集中にリアルタイムプレビューができない
- ダウンロード → 再アップロードのフローが煩雑

## 要件
- [x] GUIで操作できる
- [x] リアルタイムプレビュー
- [x] 買い切り有料アプリとして販売（BOOTH）
- [x] macOS + Windows 対応
- [x] シンプルな仕組み（メンテナンス性重視）

---

## 推奨アプローチ: Electron

### 選定理由
1. **クロスプラットフォーム**: macOS/Windows両対応が容易
2. **既存コード再利用**: `preview.js`のDOM構築ロジックをほぼそのまま使用可能
3. **シンプルさ**: JavaScript中心で開発可能（Tauriと違いRust不要）
4. **BOOTH販売との相性**: ライセンス認証不要でダウンロード配布のみでOK
5. **実績**: VS Code, Figma, Slack等で採用されている安定した技術

### 代替案との比較
| 項目 | Electron | Tauri | ブラウザSPA |
|------|----------|-------|-------------|
| アプリサイズ | 150-200MB | 10-20MB | N/A |
| 学習コスト | 低（JS only） | 高（Rust必須） | 最低 |
| クロスプラットフォーム | ◎ | ○ | △ |
| 有料販売 | ◎ | ○ | × |
| 既存コード流用 | 80%+ | 60% | 90%+ |

## 実装計画

### Phase 1: Electronプロジェクト初期化
- Electron + electron-builder のセットアップ
- Main/Rendererプロセス間のIPC通信設計
- 基本的なウィンドウ表示

### Phase 2: プレビュー機能
- 既存の`preview.js`を移植
- 既存のCSS（style.css）を適用
- JSONデータからプレビューを描画

### Phase 3: エディタUI
- CSVスキーマに基づくフォーム生成
  - 基本情報（タイトル、サークル名、発売日、価格など）
  - デザイン（アクセントカラー、背景色、画像）
  - 楽曲リスト（動的追加/削除）
  - メンバーリスト（動的追加/削除）
  - 販売リンク（動的追加/削除）
- 画像選択（ファイルダイアログ or ドラッグ&ドロップ）
- カラーピッカー

### Phase 4: ファイル操作
- プロジェクト保存/読み込み（.tokusetsu形式 = JSON + 画像のZIP）
- HTMLエクスポート（既存のXMLSerializer方式を流用）
- 画像付きでエクスポート

### Phase 5: ビルド・配布
- electron-builder でmacOS/Windowsビルド
- macOS: コード署名（Apple Developer Program要）
- Windows: インストーラー作成

## 主要技術スタック

| 項目 | 技術 | 理由 |
|------|------|------|
| フレームワーク | Electron | クロスプラットフォーム、JS中心 |
| UI | Vanilla JS + 既存SCSS | シンプル、追加学習不要 |
| プレビュー | 既存preview.js | 90%流用可能 |
| ビルド | electron-builder | デファクトスタンダード |
| パッケージ | npm | 既存環境と同じ |

## 検証方法

1. **開発中**: `npm start` でElectronアプリを起動
2. **フォーム入力テスト**: 各項目を入力してプレビューに反映されることを確認
3. **画像テスト**: 画像を選択してプレビューに表示されることを確認
4. **エクスポートテスト**: HTMLを出力し、ブラウザで正しく表示されることを確認
5. **ビルドテスト**: macOS/Windows向けにビルドし、インストール・起動を確認

## 注意事項

### コード署名について
- **macOS**: Apple Developer Program（年$99）への加入が必要
  - 署名なしでも動くが、ユーザーに「開発元不明」警告が出る
- **Windows**: 署名なしでもインストール可能（SmartScreen警告は出る）
  - EV証明書があれば警告を回避できる（高額）

### BOOTHでの販売
- ライセンスキー認証は不要（ダウンロード販売のみで十分）
- ZIP形式でアプリを配布
- macOS版は.dmg、Windows版は.exeまたはインストーラー
